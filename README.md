## 🚀 Setup
If you are here on the Github, please download these files as a ZIP so you can edit the code on your own laptop. Then open each html file in your own code editor (notepad is also usable for code editing).
Change the team name to your own team name, otherwise signals might get messed up. When you are done setting up, you can test out the files in your browser (See Use).
For optimal use, upload the files to your own Github. Then publish the github in order to use it properly, which can be done if the github is public.

---

## 💻 Use
Open a new window in your browser. Here, open a link to your published Github: https://**youraccountname**.github.io/**projectname**/lampo.html (or toktik2.html, or voluma.html)
Open the Lampo in the new window on a laptop first, then the Voluma on a phone, lastly the Toktik on the same window (different tab) on your laptop again. This ensures the timer of Toktik only starts when you have opened everything else.
